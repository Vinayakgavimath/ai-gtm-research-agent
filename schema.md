# Google Sheets Schema

## Sheet Name: GTM Research Output

| Column | Header | Description |
|--------|--------|-------------|
| A | Company | Company name submitted via webhook |
| B | What They Do | One specific sentence — what the company does and how they make money |
| C | Target Customer | Who actually buys from them (role, industry, company size) |
| D | Core Pain Point | The #1 problem their buyers feel daily |
| E | Trigger Event | Recent funding, hiring surge, product launch, or expansion that makes outreach timely |
| F | Outreach Angle | One bold cold email opener referencing the trigger event and pain point |
| G | Timestamp | Auto-populated by the n8n workflow when the row is written |

## Notes

- All 6 research fields (A–F) are generated by Groq AI (Llama 3.1) in a single API call
- Column G is appended by the Google Sheets node in n8n using `={{NOW}}` or a JavaScript date
- The sheet is append-only — each new company submission adds a new row at the bottom
- If you add the Day 6 outreach layer, add two more columns:
  - H: `Status` (default: "Not Sent", updated to "Sent" after email is dispatched)
  - I: `Sent At` (timestamp written by n8n after successful Gmail send)
