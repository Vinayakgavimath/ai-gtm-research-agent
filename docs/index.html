The Problem

Manual GTM doesn't scale

Sales and GTM teams at early-stage startups waste hours manually researching companies, finding founder emails, and writing cold outreach — work that repeats every single week.

Each step is slow, inconsistent, and completely automatable. I built a system to do all of it end to end, without a human in the loop.

What I Built

Three workflows. One pipeline.

01

GTM Research Agent

Takes a company name via webhook. Sends it to Groq AI (Llama 3.1 8B). Returns structured research — what they do, who the customer is, their pain point, a trigger event, and a personalized outreach angle. Appends everything to Google Sheets automatically.

Webhook → AI → Sheets
02

Outreach Sender

Reads rows where status = "Not Sent". Sends a personalized cold email via Gmail using the research data. Updates status to "Sent" and logs the timestamp. Rate-limited to 5 emails/day to protect deliverability.

Sheets → Gmail → Log
03

Reply Tracker + Follow-up Sequence

Checks inbox daily for replies from target founders. If a reply comes in, updates the sheet automatically. If no reply after 3 days, sends a personalized follow-up and updates status to "Follow-up Sent".

Schedule → Gmail → Sheets

The Hard Part

Prompt engineering in production

The biggest bug: Groq kept returning nested JSON objects in the who field instead of plain strings. My parser was breaking on every run.

The fix — one line
// Added to Groq API request body "response_format": { "type": "json_object" }

Forces Groq to return valid JSON every time. Combined with explicit field-level instructions and few-shot examples in the prompt, the parser hasn't broken since.

What I Learned

Automation forces systems thinking

The hardest part wasn't the automation — it was data quality. Groq would hallucinate nested objects, return wrong companies, or generate generic outreach angles that wouldn't survive contact with a real inbox.

Every bug taught me something about prompt engineering, data validation, and what "production-ready" actually means when real emails go to real founders.

Automation doesn't just save time. It forces you to think in systems — and systems expose every assumption you didn't know you were making.
